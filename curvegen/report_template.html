NGVLA subarray-selection tool

Rev F taperability & sculptability curves

Explanation

These plots show sensitivity cost (η) against angular resolution at 30 GHz, where η is the image rms divided by the rms for natural weighting. The sensitivity calculation uses underlying code similar to the ngVLA Exposure Calculator Tool (ngECT). The data come from noise simulations of each Rev F subarray for a 4 h track at declination +24°, over a grid of Briggs robust and uv-taper values with adaptive refinement where needed. The imaging curves use a selectable PSF skirt limit, s0, with a default of 10%: at each resolution the curve shows the result with the lowest η that meets the limit, or — where nothing meets it — the lowest available skirt, drawn with a hollow marker.

Subarrays that do not meet the requirements
    Explanation

    The times use the thermal-noise part of the memo-96 sensitivity model, multiplying the natural-weighting reference value by η, for a 1 h, 1 MHz reference and one pointing. Confusion is calculated from the measured sqrt(∫B2dΩ) to the first null and shown separately; it is never added to the thermal rms, and acts as a feasibility floor for MFS selection only. Where the desired sensitivity is blank, the calculator uses the natural, untapered MAIN sensitivity in one minute at the selected frequency and bandwidth as a ranking scale. Kelvin goals are converted separately using each candidate's achieved beam.

    The efficient rank is the fraction of physical antenna pairs in the requested science interval; performance is the number of those pairs. The interval runs from Bmin = LAS coefficient × λ / LAS to Bmax = 1.02λ / requested resolution, with angles in radians and inclusive endpoints, and the denominator counts all distinct antenna pairs. Where no LAS is requested, Bmin assumes LAS = 10× the requested resolution — an assumption of the metric, not a supplied requirement — which the summary line flags whenever it applies. It has no effect on the antenna-hours and time ranks. Pair lengths are physical, unprojected distances; source-direction projection and asymmetric uv coverage remain future work. Main and Main+Long stay eligible wherever they meet the requirements, these scores do not change the modeled times, and the measured curves above still decide beam and PSF feasibility.

    Times exclude overheads, and the model does not capture the difference in band averaging between spectral-line and continuum observations. The visibility count is the number of cross-correlation samples in the observation, assuming one channel, no autocorrelations, and one correlator dump every 5 s.

    Explanation

    At each target resolution, the curve shows the beam with the lowest η that meets the selected PSF skirt limit; the interpolation engine calculates values continuously across resolution. Where no beam meets the limit, the curve falls back to the lowest available skirt, drawn as a hollow triangle — point to one to see the skirt value it actually achieves. Dashed vertical lines show the largest angular scale (LAS) for each subarray at 30 GHz; subarrays containing the core share a minimum baseline and therefore a LAS.     Valid simulation results

    Explanation

    These plots show simulation results for which η ≤ 5. Circles are natural weighting with taper, squares Briggs weighting without taper, and triangles Briggs weighting with taper. Filled markers meet the 10% reference skirt limit; hollow ones do not. Point to a marker to see its parameters.

    These plots show the same simulation results in uv-taper and robust space, one dot per result, with the natural row carrying natural weighting. The taper axis is linear so that concentrations and gaps are easy to see. Filled colored dots are residual-validated: every adaptive cell touching the point passed the convergence test. Hollow colored dots touch at least one cell that did not; audit-limited, wave-limited, and non-residual retirements do not count as validated. Small gray dots — on the natural row, on the untapered seam, or outside the quadtree — were not assessed. Gaps mark regions with few results or none. Point to a dot to see its parameters.

    Sweep grid in robust and taper space

    Explanation

    Each plot shows the full sweep grid for one subarray. Rows are natural weighting and Briggs robust from +2 to −2; columns are uv-taper values. Color shows η, light near 1 and dark near 5. A dot marks a result meeting the default 10% skirt limit, and a border marks one the default imaging curve uses. Striped cells are beam-cap anchors, for diagnosis only; a slash is a cell skipped after the row reached the beam cap, an X a failed simulation, and an empty cell has no result. Point to a measured cell to see its beam, η, and skirt.

    PSF inspector

    Explanation

    Select a subarray to examine its measured PSF, or reach the same thing by selecting a marker in the simulation-results plots, a cell in the sweep grid, or a PSF button in the calculator, which opens the PSF below that row. The page loads profile data only when you request it. The internal report reads the adjacent psf/ directory, so keep that directory with the HTML file; the release page embeds the profile data and does not need it.
